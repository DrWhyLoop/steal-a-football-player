- Lean code: no dead code, no unused functions/variables, no duplicated logic. Reuse helpers. Smallest clear solution wins, but stay readable (no code golf).
- Before adding code, check whether existing code can be extended instead.
- After each task, remove anything your change made unused.
- Server-authoritative: the server validates all damage, drops, carrying, placing, stealing and cash. Clients only send requests.

- Always show a plan and wait for my OK before building.

# Game overview
"Steal a Footballer" — a Roblox steal-and-collect game (like Steal a Brainrot / Steal an Egg) with original cartoon football-legend characters.

Core loop:
- Players mine collectible egg meshes with a pickaxe in a 12-stage hallway (Stage 1 nearest the bases, 192 studs wide; stages 1-8 are about 257.14 studs long, stages 9-10 are 321.43, stage 11 is 385.71 and stage 12 is 514.29; total stage pathway 3,600 studs).
- A broken egg drops a character card of that stage's tier; the player carries it back (slower for higher tiers) and places it on one of 30 raised displays across three floors of their plot. Placed characters earn cash per second.
- Tiers: Stages 1-2 Common, 3-4 Rare, 5-7 Epic, 8-9 Legendary, 10-11 Mythic, 12 GOAT. GOAT cubes only spawn as a timed Stage 12 event. A random Golden Cube (stages 4-11) drops one tier higher, capped at Mythic.
- 6 plots per server, max 6 players.

Built so far: full-map grassy terrain and nearby client-generated landscaping, perimeter collision/grass-top borders, 120 budgeted torches, synchronized sunny/rain/evening/night weather; greybox world, six tiered egg designs using the cube mining system, ground-floor plot fences, cards, carrying, plots with 180 working gray displays, green earnings panels, separate yellow upgrade panels, cash, Golden Cube; pickaxe mining/combat with hit/miss sounds and server line-of-sight checks; stealing with original-owner validation, reserved slots marked BEING STOLEN, and recovery on pickaxe/guard hits; base lock with a 60s barrier, 30s cooldown and both countdowns; 28 imported-monster stage guards with patrol/chase, nearby-player activation, distance-limited effects and client knockback.
